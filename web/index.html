Stuck Loading?

Common issues and fixes. If you're still stuck, check the server terminal where python server.py is running.

Is the bot in any servers?

Your bot needs to be in at least 1 server. Create a test server, invite the bot, then log in again.

Are the privileged intents enabled?

Botcord needs the Server Members, Message Content and Presence privileged gateway intents enabled on the developer portal under Bot settings.

Clearing saved data

If the loading screen is stuck on "Logging into the bot", your saved token may be wrong. Clear it and try again.
